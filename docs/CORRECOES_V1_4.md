# AEVIA 1.4 — Direitos de fotografia explicados sem siglas

- A pergunta de licença só aparece quando uma foto é selecionada.
- O visitante escolhe o motivo pelo qual pode compartilhá-la: autoria/titularidade, autorização, licença aberta com fonte, ou domínio público documentado.
- Para fotos de licença aberta, a opção CC BY/CC BY-SA fica em segunda etapa, com campo de referência.
- A opção “não sei” explica que se deve remover a foto, podendo enviar o relato.
- O servidor impede envio de imagem sem declaração e comprovação quando apropriado.
- Os metadados de direitos ficam na fila para revisão humana.
- Históricos existentes são preservados por migração de duas colunas da base de dados.
- Porta local: 8014 para evitar versões antigas em execução.
- Os termos permanecem minuta e exigem revisão antes de publicar o serviço para usuários reais.

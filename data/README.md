# Cadastro nacional de municípios

Esta cópia permite a pesquisa offline no AEVIA Beta. Fonte dos nomes, códigos IBGE e coordenadas aproximadas: [Municípios Brasileiros — Kelvin S. do Prado](https://github.com/kelvins/Municipios-Brasileiros), arquivo `csv/municipios.csv`, licença MIT (ver `LICENSE_MUNICIPIOS_MIT.txt`).

São **5.571 municípios** na base de referência incluída no projeto, incluindo Boa Esperança do Norte (MT). O dataset é de manutenção comunitária e pode ficar desatualizado; a sincronização oficial com o IBGE continua disponível para atualização. As coordenadas são aproximadas e não representam o endereço exato da rua nem a localização de uma fotografia. Os campos originais não usados foram removidos nesta cópia.

O arquivo deve continuar no repositório e na imagem Docker. Sem ele, um novo servidor que não tenha acesso à API oficial não terá cobertura nacional.
